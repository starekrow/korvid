# goldberg's window fixture

A small tree for `goldberg watch --window --demo` (`tools/goldberg/README.md`): a rule file for
the Rules and Diff pages, art its rules type, a screen, a screen that fails to compile (Reports'
failures), and a file nothing types (Reports' warnings). The demo copies it to a directory of
its own first, since it saves the rule file:

```
tools/goldberg/tests/window/run.sh [TARGET]
```
